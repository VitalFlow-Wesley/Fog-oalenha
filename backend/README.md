# Backend Fogão a Lenha

API em Node.js/Express para ligar o app a um banco MongoDB.

## Como usar

1. Entre na pasta:

```bash
cd backend
```

2. Instale dependências:

```bash
npm install
```

3. Crie o arquivo `.env` baseado no `.env.example`.

4. Rode em desenvolvimento:

```bash
npm run dev
```

## Primeiros módulos

- Usuários
- Produtos
- Mesas
- Comandas
- Pedidos enviados
- Fechamento de caixa
- Configurações
